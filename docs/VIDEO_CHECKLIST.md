# Exercise clips checklist

Put each clip in `web/videos/` with the exact file name below (lowercase).
Short is best: **5–15 seconds**, MP4 (H.264), no sound needed, ideally under 5 MB. Clips play muted and loop.
Exercises without a clip show an icon instead.

After adding clips, run `npm run compress-videos` (in FitnessTrackerApp). It shrinks them to HD
and makes the thumbnails (`<name>.jpg`). Keep your own copy of the original clips; the files here are replaced by the smaller versions.
